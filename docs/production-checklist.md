# Checklist de Produção

- [ ] Segredos em cofre (nunca em git).
- [ ] HTTPS obrigatório e HSTS.
- [ ] CORS restrito por ambiente.
- [ ] Rate limiting e proteção brute force.
- [ ] JWT/refresh rotativo com hash e revogação.
- [ ] Migrações Prisma revisadas.
- [ ] Políticas LGPD publicadas e versionadas.
- [ ] Fluxo de exportação/exclusão auditável.
- [ ] RevenueCat webhook validado.
- [ ] AdMob desabilitado em telas sensíveis.
- [ ] Alertas/monitoramento/telemetria ativos.
- [ ] Backup e disaster recovery.
- [ ] CI com lint/test/build/e2e.
